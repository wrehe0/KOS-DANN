# Шпаргалка: Редактирование текста и командная строка

## ⌨️ Горячие клавиши (Универсальные)

Эти комбинации работают в большинстве текстовых редакторов (Word, Google Docs, Блокнот, IDE) и полях ввода браузеров.

### Выделение и навигация (без мыши)
| Действие | Windows / Linux | macOS |
| :--- | :--- | :--- |
| **Переместить курсор** | `←` `→` `↑` `↓` | `←` `→` `↑` `↓` |
| **Слово назад/вперед** | `Ctrl + ←` / `→` | `Option + ←` / `→` |
| **В начало/конец строки** | `Home` / `End` | `Cmd + ←` / `→` |
| **В начало/конец документа** | `Ctrl + Home` / `End` | `Cmd + ↑` / `↓` |
| **Выделить всё** | `Ctrl + A` | `Cmd + A` |
| **Выделить слово** | Двойной клик мыши | Двойной клик мыши |
| **Выделить строку** | Тройной клик | Тройной клик |
| **Выделить по буквам** | `Shift + ←/→` | `Shift + ←/→` |
| **Выделить по словам** | `Ctrl + Shift + ←/→` | `Option + Shift + ←/→` |

### Редактирование текста
| Действие | Windows / Linux | macOS |
| :--- | :--- | :--- |
| **Копировать** | `Ctrl + C` | `Cmd + C` |
| **Вырезать** | `Ctrl + X` | `Cmd + X` |
| **Вставить** | `Ctrl + V` | `Cmd + V` |
| **Отменить (Undo)** | `Ctrl + Z` | `Cmd + Z` |
| **Вернуть (Redo)** | `Ctrl + Y` (или `Ctrl + Shift + Z`) | `Cmd + Shift + Z` |
| **Жирный текст** | `Ctrl + B` | `Cmd + B` |
| *Курсив* | `Ctrl + I` | `Cmd + I` |
| <u>Подчеркнутый</u> | `Ctrl + U` | `Cmd + U` |
| **Удалить слово назад** | `Ctrl + Backspace` | `Option + Delete` |
| **Удалить слово вперед** | `Ctrl + Delete` | `Option + Fn + Delete` |

## 🖥️ Командная строка (Windows CMD / PowerShell)

| Команда | Действие |
| :--- | :--- |
| `dir` | Показать список файлов и папок в текущей директории |
| `cd <папка>` | Перейти в указанную папку |
| `cd ..` | Подняться на один уровень вверх (в родительскую папку) |
| `cd \` | Перейти в корень диска |
| `mkdir <имя>` | Создать новую папку |
| `rmdir <имя>` | Удалить **пустую** папку |
| `del <файл>` | Удалить файл |
| `copy <источник> <назначение>` | Копировать файл |
| `move <источник> <назначение>` | Переместить или переименовать файл |
| `cls` | Очистить экран терминала |
| `exit` | Закрыть окно командной строки |
| `ipconfig` | Показать настройки сети (IP-адрес) |
| `ping <адрес>` | Проверить связь с сервером (например, `ping google.com`) |

## 🐧 Командная строка (Linux / macOS / Git Bash)

| Команда | Действие |
| :--- | :--- |
| `ls` | Показать список файлов и папок |
| `ls -la` | Показать **все** файлы (включая скрытые) с подробной информацией |
| `pwd` | Показать полный путь к текущей папке (где я сейчас) |
| `cd <папка>` | Перейти в папку |
| `cd ~` | Перейти в домашнюю директорию пользователя |
| `mkdir <имя>` | Создать папку |
| `rm <файл>` | Удалить файл |
| `rm -r <папка>` | Удалить папку **со всем содержимым** (осторожно!) |
| `cp <источник> <назначение>` | Копировать файл/папку |
| `mv <источник> <назначение>` | Переместить или переименовать |
| `clear` (или `Ctrl + L`) | Очистить экран |
| `sudo <команда>` | Выполнить команду с правами администратора (суперпользователя) |
| `man <команда>` | Открыть руководство по команде (например, `man ls`) |

## Полезные "фишки" для терминала

1.  **Автодополнение (Tab)**: Начните вводить имя файла или папки и нажмите `Tab` — терминал допишет название сам. Нажмите дважды — покажет варианты.
2.  **История команд (Стрелки)**:
    *   `↑` (Вверх) — вызвать предыдущую команду.
    *   `↓` (Вниз) — вызвать следующую команду.
3.  **Остановка выполнения**: Если программа "зависла" или выводит слишком много текста, нажмите `Ctrl + C`, чтобы прервать её выполнение.
